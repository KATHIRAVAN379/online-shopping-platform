# Online Shopping Platform

A full-stack online shopping platform built with Spring Boot microservices on the backend and Angular on the frontend.

## Tech Stack
- Backend: Java, Spring Boot, Spring Cloud, Maven
- Frontend: Angular
- Service Discovery: Eureka
- API Gateway: Spring Cloud Gateway

## Project Structure
- `backend/` - microservices backend
- `frontend/` - Angular application

## Getting Started

### Backend
```bash
cd backend
./mvnw clean install
```

### Frontend
```bash
cd frontend
npm install
npm start
```

## Notes
This project is intended to be developed and run locally before deployment.
